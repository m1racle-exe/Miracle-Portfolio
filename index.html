UBAYAPost

Mata kuliah Human-Computer Interaction · tim 5 orang · peran saya: prototyper

Informasi kegiatan kampus di UBAYA tersebar di Instagram, grup WhatsApp dan LINE, serta dari mulut ke mulut. Mahasiswa yang tidak aktif berorganisasi sering terlambat mengetahuinya. UBAYAPost adalah aplikasi seluler yang menyatukan semua acara, open recruitment kepanitiaan, dan seminar dalam satu feed yang bisa dicari. Proyek ini mendukung SDG 4 (Pendidikan Berkualitas) dengan memberi seluruh mahasiswa akses yang sama ke kegiatan pengembangan keterampilan.

Yang saya kerjakan

  • Membuat prototipe Figma high-fidelity yang mencakup alur utama aplikasi, dari login sampai pendaftaran kegiatan.
  • Merancang antarmuka yang sederhana, konsisten, dan selaras dengan identitas visual UBAYA.
  • Mengevaluasi prototipe dengan heuristic evaluation dan merumuskan perbaikan untuk versi berikutnya.

Virtual Private Server di Azure

Mata kuliah Sistem Operasi · tim 5 orang · peran saya: root user

Kelompok kami membuat virtual machine Ubuntu Server 24.04 di Microsoft Azure dan mengelolanya seperti server produksi kecil. Setiap anggota punya akun dan website pribadi, dan hanya ketua tim yang punya akses sudo.

Yang saya kerjakan

  • Membuat VM, menentukan ukuran, penyimpanan, dan aturan jaringannya, lalu menguji akses SSH.
  • Menyusun struktur dan menulis laporan proyek yang mendokumentasikan setiap langkah.
  • Menyiapkan akun dan memastikan pengguna biasa ditolak saat memakai sudo, sedangkan ketua diizinkan.

Layanan di server

Apache web server dengan virtual directory untuk tiap anggota, MySQL, PHP, phpMyAdmin, SSH, dan vsftpd untuk transfer file lewat WinSCP. Untuk pemeliharaan kami memakai cron untuk backup dan update, firewall UFW, hardening SSH, dan ClamAV.

Jaringan Multi-Router dengan Cisco Packet Tracer

Tugas praktik jaringan · simulasi di Cisco Packet Tracer

Topologi terdiri dari empat router yang saling terhubung dan empat subnet. Setiap subnet punya switch, server DHCP, dan beberapa PC, sedangkan dua subnet juga memiliki web server. Tugasnya adalah memperluas Subnet D ketika jumlah perangkatnya bertambah, tanpa memutus konektivitas ke subnet lain.

Yang saya kerjakan

  • Menambah tiga PC baru ke Subnet D, sehingga kebutuhan alamat naik dari empat menjadi tujuh perangkat.
  • Menghitung ulang CIDR: prefix /29 hanya muat enam host, jadi saya memilih /28 yang cukup untuk tujuh host dan masih punya ruang tumbuh.
  • Memperbarui server DHCP Subnet D (subnet mask dan jumlah pengguna maksimum), konfigurasi IP server tersebut, serta antarmuka router R4 yang melayani subnet itu.
  • Menambahkan static route ke Subnet D yang baru pada router lain dan menyesuaikan next hop di tiap router.
  • Menguji konektivitas dengan ping (ICMP) antara PC di Subnet A dan Subnet D dari kedua arah, termasuk PC baru. Semua balasan diterima.
